# Use focused dependencies at untrusted boundaries

The gateway will use exactly pinned `jose` and one focused schema-validation runtime dependency: `jose` owns PKCS#8 import and RS256 service-account JWT construction, while the validator covers Matrix requests, individual installations, Worker configuration, OAuth responses, and FCM responses without changing Matrix rejection or unknown-field semantics. Direct FCM HTTP v1 delivery, OAuth exchange and caching, D1 coordination, payload construction, retry policy, and error classification remain gateway-owned. Firebase Admin and Google Auth were rejected because their measured Worker bundles were hundreds of kilobytes, their Node-oriented compatibility surface was unnecessary, and their retry/error abstractions conflicted with Matrix delivery semantics. CI permits only these two runtime packages and enforces Cloudflare Workers Free-plan limits while reporting actual raw and gzip size.
