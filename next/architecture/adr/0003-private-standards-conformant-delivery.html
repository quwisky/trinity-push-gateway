Prefer private, standards-conformant delivery ​

Delivery Messages will carry identifiers and counts rather than message content, with Trinity's mobile clients responsible for fetching and decrypting events. An opaque Account Route will replace the existing practice of forwarding a Matrix user ID. Android will receive high-priority data and render locally; iOS will receive a generic visible fallback that its Notification Service Extension can replace after syncing and decrypting. These behaviors require companion changes in both mobile clients, which are explicitly outside this repository and implementation task. The gateway will implement Matrix duplicate suppression and rejected-key reporting using narrowly scoped expiring state, accepting that this small stateful component is necessary for correct behavior while remaining within Cloudflare's free tier.
