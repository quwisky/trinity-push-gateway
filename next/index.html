Trinity Push GatewayPrivate Matrix notifications through Firebase

A small, single-tenant gateway for Cloudflare Workers or self-hosted Bun.

Deploy on Cloudflare
Self-host with Docker

Matrix-compatible

Accepts the standard Matrix push notification contract without requiring a custom homeserver integration.

Privacy-preserving

Sends private data-only FCM messages and deliberately excludes Matrix content and identifiers from logs.

Two supported runtimes

Run on the Cloudflare free-plan envelope with D1, or as one Bun container with durable SQLite storage.

The gateway translates Matrix push notifications into Firebase Cloud Messaging requests for Trinity Android and iOS applications. It does not contain mobile client code or a hosted multi-tenant service.
